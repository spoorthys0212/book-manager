# Book Manager

A full-stack Book Management application built using:

- React
- Tailwind CSS
- Java
- Spring Boot
- MySQL

## Features

- User Login
- Add Books
- View Books
- Edit Books
- Delete Books
- Search and manage book details

## Project Structure

- frontend - React + Tailwind CSS
- backend - Java + Spring Boot
